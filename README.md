# PocketWise AI 
### Your Smart Financial Coach

**PocketWise AI** is a proposed student-focused financial assistant designed to help college students track expenses, plan budgets, and make informed spending decisions.

## Problem Statement

College students often struggle to track daily expenses, control spending, and manage their monthly budgets effectively. PocketWise AI aims to simplify personal budgeting through expense analysis and practical financial insights.

## Proposed Features

- **Smart Expense Tracking:** Record and categorize daily expenses.
- **Receipt Scanner:** Extract expense details from receipt images using OCR.
- **Month-End Forecast:** Estimate monthly spending based on current spending patterns.
- **Purchase Affordability Simulator:** Understand how a planned purchase may affect the remaining budget.
- **Daily Spending Limit:** Calculate a suggested daily spending limit.
- **Budget Runway Predictor:** Estimate how long the remaining balance may last.
- **Unusual Spending Detection:** Identify potentially unusual changes in spending patterns.

## Proposed Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python and Flask
- Database: SQLite
- Receipt Processing: OCR
- Financial Analysis: Python-based calculations and statistical rules

## Proposed Workflow

1. Enter expenses manually or upload a receipt.
2. Process and categorize expense information.
3. Calculate total spending and remaining budget.
4. Analyze spending patterns and estimate future expenses.
5. Provide budget summaries, spending recommendations, and alerts.
